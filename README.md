# Bab Al Hara Restaurant Platform

Production bilingual restaurant ordering and operations platform.

## Stack
- Frontend: Angular
- Backend: ASP.NET Core / .NET
- Real-time: SignalR
- Payments: Paymob integration
- Notifications: WhatsApp provider integration
- Languages: Arabic RTL + English LTR

## Product surfaces
- Customer ordering
- Kitchen display
- Cashier
- Driver
- Manager
- Admin
